tynt is a browser-based fantasy console. Games are small TypeScript cartridges built around three functions: `init`, `update`, and `draw`.

Create games in the browser, save them locally, and export them as `.tynt` files. To contribute a game to the public gallery, submit a pull request to the repository for validation and review.

- [Create a game](https://tynt.dev)
- [Explore the gallery](https://tynt.dev/gallery)
- [Documentation](https://docs.tynt.dev)
- [Source code](https://github.com/cristianbgp/tynt)
